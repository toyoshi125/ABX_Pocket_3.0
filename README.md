# ABX Pocket 3.0 — 患者から選ぶ

GitHub Pages 用静的Webアプリ。ZIPを解凍して **中身のファイルすべて** をリポジトリのルートに配置してください。Settings > Pages > Deploy from a branch > main / (root)。

- 初期画面は患者情報を選ぶウィザード形式
- 既存の感染症別11領域の条件分岐、薬剤検索70種、腎機能別参考表34薬剤を引き継ぐ
- 患者背景、アレルギー、腎機能、妊娠、免疫不全、ショックの安全確認
- 年齢・体重・血清CrからCockcroft–Gault式のCCrを算出し、薬剤別表へ連携
- 患者情報はサーバーに送信しない。お気に入り薬剤コードのみlocalStorage保存

**重要**：原典との分岐別照合・国内承認用量の照合・専門家レビュー未完了の試作版です。患者別の確定処方指示には使用しないでください。AKI・透析・妊娠・重症例は別途評価が必要です。

新規リポジトリ名の例: `ABX_Pocket_3.0`。公開URL例: `https://toyoshi125.github.io/ABX_Pocket_3.0/`。
